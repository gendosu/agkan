# 設計仕様: `fable-issue-hunt` スキル

- 作成日: 2026-07-02
- 対象プロジェクト: agkan（TypeScript 製 CLI かんばんタスク管理ツール）
- 種別: Claude Code スキル

## 1. 目的

呼び出すと、Fable 5 が agkan コードベースの課題を多角的に発見し、そのまま agkan
タスクとして登録するスキルを提供する。オーケストレーター（メインセッション）は探索・
統合・登録を統括し、Fable サブエージェントが実際の発見を担う。

## 2. スコープ

- 対象: `src/`（本体ロジック）と `tests/`（テスト資産）を中心とした agkan リポジトリ
- 発見する課題の種類（4軸すべて）:
  - バグ・不具合
  - 技術的負債・設計
  - テスト・品質
  - UX・機能改善
- 非対象: 無関係な大規模リファクタ提案、依存ライブラリの内部課題

## 3. 実行アーキテクチャ（次元別並列 Fable）

オーケストレーターが以下の順で実行する。

1. **事前準備**
   - `agkan list`（必要に応じて全ステータス）で既存タスク一覧を取得し、重複排除の
     基準集合を作る
   - 対象ディレクトリ構成を把握する
2. **並列探索**
   - `model=fable` のサブエージェントを 4 つ**並列**に spawn する（1 メッセージ内で
     複数 Agent 呼び出し）
   - 各エージェントは 1 軸だけに専念し、構造化 findings を返す
3. **統合・重複排除**
   - 4 軸の findings を集約する
   - 既存 agkan タスクおよび findings 相互間の重複を除外する
4. **登録**
   - 残った findings を `agkan add` でタスク化する（フィールド・タグ規則は第 5 節）
   - 完全自動で全件登録する（登録前の確認は行わない）
5. **報告**
   - 登録件数・軸別内訳・スキップした重複を一覧でサマリ表示する

## 4. Fable に渡す探索プロンプトの核

各軸サブエージェント共通の骨子。

- **コンテキスト付与**: 「agkan = TypeScript 製 CLI かんばんタスク管理ツール」＋主要
  ディレクトリ（`src/`, `tests/`）
- **証拠主義の強制**:
  - 全 finding に `file:line` と具体的根拠を必須化する
  - 推測・「おそらく」・「可能性」・「将来実装予定」といった記述を禁止する
  - 実際にコードで確認できた事実のみを finding とする
- **出力スキーマ固定**（JSON）:
  - `title`: 簡潔な課題名（日本語）
  - `dimension`: bug | tech-debt | test | ux
  - `severity`: high | medium | low
  - `evidence`: `file:line` と根拠の説明
  - `suggestion`: 対処の方向性
- **軸ごとの評価レンズ**を明示する:
  - バグ軸: 実際に動作を壊す欠陥のみ。理論上の懸念は除外
  - 技術的負債軸: 肥大化ファイル・責務の曖昧さ・重複・境界不明瞭
  - テスト軸: カバレッジ不足・脆いテスト・CI/品質のギャップ
  - UX 軸: CLI の使い勝手・Board 機能・不足機能

## 5. agkan 登録フィールドとタグ規則

- `title`: finding の title
- `body`: evidence と suggestion を含む説明（Markdown）
- `priority`: severity から写像（high→高 / medium→中 / low→低。実際の agkan の
  priority 表現に合わせる）
- **タグ**（プロジェクト規約準拠）:
  - Board 機能・Board 関連 → `board`
  - CLI コマンド・CLI 改善 → `cli`
  - 両方に該当すれば両方付与、どちらでもなければタグなし
- 既存タスクと重複するものはスキップし、報告に明記する

## 6. 安全性

- 完全自動登録だが、末尾に**登録した全タスクの一覧**（title / dimension / tag /
  agkan タスク ID）を必ず提示し、ユーザーが後追いで精査できるようにする
- スキップした重複も同時に提示する

## 7. スキルのメタ情報

- 名称: `fable-issue-hunt`
- description: 「プロジェクトの課題を Fable 5 で洗い出して agkan タスク化したいとき。
  『課題を棚卸し』『Fable で課題発見』『タスク化して』等で発火」
- 実装は skill-creator を用いる

## 8. 成功基準

- スキル呼び出しだけで、4 軸の課題が並列に発見され、重複を除いて agkan に登録される
- 各タスクが `file:line` 根拠付きで、推測表現を含まない
- 登録結果が軸別内訳付きで報告される
